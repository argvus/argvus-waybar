# argvus-waybar

Waybar packaged for the ARGVUS desktop with immutable click coordinates for
shell popups.

## Build

On Arch Linux or a compatible distribution:

    make validate
    make build

The resulting package is written to build/dist/. See DEVELOPMENT.md for the
repository layout and release flow.
