# Security Policy

## Supported Versions

Only the latest tagged release is actively supported.

| Version | Supported |
| ------- | --------- |
| latest tag | Yes |
| older releases | No |

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Report them
privately through GitHub Security Advisories:
https://github.com/argvus/argvus-waybar/security/advisories/new

Include the affected version, package name argvus-waybar, reproduction steps,
impact, and a suggested fix when possible.

## Scope

This project produces an Arch Linux package built from this repository.
Security-sensitive behavior includes the pinned source archive and patch used
by packaging/arch/ci/PKGBUILD.
